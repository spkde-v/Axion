# Axion — Shopify theme

Theme for **Axion**, a mechanical keyboard store (keyboards, switches, keycaps).
Built on top of Shopify's [Skeleton theme](https://github.com/Shopify/skeleton-theme).

Soft, rounded, light design in the palette `#FCF9EA` · `#DB9558` · `#97A87A` · `#A8BBA3`.
Buttons look and "press" like keycaps. All illustrations are hand-drawn SVGs in `assets/illo-*.svg`
(generated by `assets/axion-render.js`); every section with artwork also has an image picker for real photos.

## Build Your Keyboard

The `keyboard-builder` section (template `page.builder`) lets customers pick a base, switches and keycaps,
shows a live SVG preview of the board, and adds the whole build to the cart in one click.
Each line item gets a `Build: AX-1234` property, which the cart displays.

Setup:

1. Create a page (e.g. handle `build`) and assign the **page.builder** template. The header button and hero link to `/pages/build` by default.
2. In the theme editor, choose three collections in the builder section: keyboards, switches, keycaps.
3. Tag products so the preview can draw them:

| Product  | Tags                                               | Example                                    |
|----------|----------------------------------------------------|--------------------------------------------|
| Keyboard | `layout:60` / `65` / `75` / `tkl`, `case:#HEX`     | `layout:65`, `case:#97A87A`                |
| Switch   | `switch:linear` / `tactile` / `clicky`, `stem:#HEX`| `switch:tactile`, `stem:#8C6B4F`           |
| Keycaps  | `cap:#HEX`, `mod:#HEX`, `accent:#HEX`              | `cap:#FCF9EA`, `mod:#A8BBA3`, `accent:#DB9558` |

4. Switch quantity: sell **in packs** (packs = ⌈keys / pack size⌉) or **per switch** (quantity = number of keys: 60% → 61, 65% → 68, 75% → 84, TKL → 87).
5. Optional: pick an "Assembly & lubing" service product; it appears as a checkbox.

Until collections are connected, the builder runs in demo mode with sample parts (checkout disabled).
Selections are kept in the URL (`?base=…&switch=…&caps=…`), so a build can be shared as a link.

## Sections

Home: `hero`, `features`, `category-tiles`, `builder-promo`, `featured-collection`, `switch-guide`, `testimonials`.
Also restyled product (variant pills, gallery, AJAX add to cart), collection (filters and sorting), cart, search, blog, article, 404, password.

Locales: English (default) and Russian.
